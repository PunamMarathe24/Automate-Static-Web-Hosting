# Automated Static Website Hosting using AWS S3 and Python SDK

## 📌 Project Overview
This project demonstrates how to automate static website deployment on AWS S3 using Python (boto3 SDK).

---

## 🎯 Objective
To upload and host a static website on S3 without manual upload using automation.

---

## 🧰 AWS Services Used
- Amazon S3
- boto3 (Python SDK)

---

## 📁 Project Structure
- upload_script.py → Python automation script
- website/ → static website files
- screenshots/ → project screenshots

---

## ⚙️ How It Works
1. Create an S3 bucket
2. Enable static website hosting
3. Run Python script to upload files
4. Access website using S3 URL
